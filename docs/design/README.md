# design

## Purpose

Design considerations for qkit's vendor-facing product: the rules a feature must meet, the audit of today's vendor journey, and proposed slices. These are proposals. Nothing here is scheduled until the owner approves it.

## Contents

- `vendor-time-principles.md`: turns design partner Manfred's feedback into one rule (give vendors time back for serving and talking to customers), a six-question feature checklist, a journey and workflow audit with verified code paths, an education plan (hints, tour, help center, videos) and proposed implementation slices.
